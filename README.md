# Term Planner

A term planner that runs entirely in your browser. No account, no sign-up, and nothing you enter ever leaves your device.

**Try it:** https://mdbros0.github.io/term-planner/

## Getting started

1. Open the link in any modern browser, on your phone or computer. A welcome overlay walks you through it the first time; you can always find Help in Settings.
2. It starts with fictional DEMO sample courses so you can try everything right away.
3. Make it yours: go to **Courses → + Add course** to build your own course, or import a course file a classmate shared. Remove the sample courses with **Courses → Remove course**.
4. Tick items off as you finish them. **Today** shows this week with your next deadline up top; **Grades** shows your marks. You can add custom tasks, notes, and marks.
5. Everything saves automatically in your browser — look for the "Saved on this device" pill.

## Moving devices and backups

There is no sync, so a new device starts empty. Back up regularly:

- **Whole app:** Settings → Export backup saves everything (courses, ticks, marks, notes, custom tasks) as one `.json` file. On another device, Settings → Import backup restores it. Import replaces everything on that device, so export first if you have anything to keep.
- **One course:** Courses → Export course saves just that course as `.json`. A classmate can import it under Add course. If a course outline changes later, Courses → Re-import outline updates it.

## Install it like an app

- **Android (Chrome):** menu → Add to Home screen, or Install app.
- **iPhone (Safari):** Share → Add to Home Screen.
- Open it from the hosted link above — opening a downloaded copy of the file directly from disk can't install or work offline.

## Offline

Open it once while you're online and it caches itself on your device, then it keeps working offline. Your data is stored in your browser, so the planner works without a connection once it's loaded.

## About

Single-file progressive web app: `index.html` + `manifest.webmanifest` + `sw.js`. The sample courses are fully fictional DEMO data — no real institution, people, or contacts.
